📊 statdesign - created by KLIDE

statdesign ist ein individuelles Statistik-Design-Tool, das speziell für Rocket League-Spieler entwickelt wurde, um ihren Fortschritt und ihre Leistung direkt im Spiel zu verfolgen. 🚀

Dieses Projekt liefert dir ein einzigartiges Design-Theme für das beliebte RocketStats-Plugin in BakkesMod.

✨ Features

    Gewinn-/Verlust-Zähler: Zählt automatisch die Gesamtzahl deiner Siege und Niederlagen in deinen Spiel-Sessions, um deine Erfolgsquote direkt im Auge zu behalten.

    Aktuelle Rang-Anzeige: Zeigt deinen aktuellen Rang im Spiel an, damit du deinen Aufstieg (oder Abstieg!) in Echtzeit verfolgen kannst.

    Minimalistisches Design: Das Theme wurde mit Fokus auf ein dezentes und cleanes Design entwickelt, das alle wichtigen Informationen liefert, ohne dich vom Spielgeschehen abzulenken.

    Einfache Integration: Das Design ist für die sofortige Nutzung mit dem RocketStats-Plugin (BakkesMod) konzipiert.

🛠️ Installation

Um dieses Theme zu verwenden, benötigst du das RocketStats-Plugin für BakkesMod.

    Plugin installieren: Lade das RocketStats-Plugin hier herunter und installiere es: https://bakkesplugins.com/plugin/30

    Theme-Ordner finden: Navigiere zum RocketStats-Theme-Verzeichnis auf deinem PC:

    C:\Users\klide\AppData\Roaming\bakkesmod\bakkesmod\data\RocketStats\RocketStats_themes

    Dateien einfügen: Kopiere die Dateien aus diesem Repository (config.json, fonts, images) in den oben genannten RocketStats_themes-Ordner.

    Aktivieren: Wähle das statdesign-Theme im BakkesMod-Menü aus, um es zu aktivieren!
